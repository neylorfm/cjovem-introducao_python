Ambiente Computacional Local

1. Instalação do Anaconda3 no Computador (Linux)

Linux / Ubuntu • Distribuição Científica

O Anaconda é uma distribuição completa para computação científica e programação, trazendo nativamente o interpretador Python oficial, os gerenciadores de pacotes (conda e pip), bibliotecas fundamentais e o ecossistema de cadernos interativos Jupyter Notebook.

Passo 1: Download do Instalador

Script Shell (.sh)

Acesse a página oficial de download no navegador do computador:

🔗 Download Oficial do Anaconda (Linux x86_64)
  • O arquivo baixado para a pasta ~/Downloads possui a extensão shell script (exemplo: Anaconda3-2024.xx-Linux-x86_64.sh).
  • Certifique-se de que o download foi concluído antes de iniciar a instalação no terminal.

Passo 2: Instalação via Terminal

  1. Abra o terminal do sistema pressionando o atalho Ctrl + Alt + T.
  2. Navegue até a pasta de transferências:
    cd ~/Downloads
  3. Inicie o instalador executando o script com o interpretador bash:
    bash Anaconda3-*.sh
  4. Instruções durante a execução:
    • Pressione Enter para rolar os termos de licença e, ao final, digite yes para aceitar.
    • Confirme o diretório padrão de instalação pressionando Enter.
    • Quando o instalador perguntar se deseja inicializar o Anaconda no terminal (initialize Anaconda3), digite yes.

Passo 3: Ativação do Ambiente Base

Após a instalação, ative o ambiente base do Anaconda através do caminho do usuário:

source /home/cjovem/anaconda3/bin/activate

Nota: Caso o caminho tenha sido personalizado em outro diretório de usuário, ajuste para o seu caminho correspondente (exemplo: source ~/anaconda3/bin/activate).

Indicador de Sucesso: Ao ativar, o terminal exibirá o prefixo (base) no início da linha de comandos:
(base) cjovem@lab-ti:~$
Ambiente de Cadernos Interativos

2. Inicialização e Utilização do Jupyter Notebook

Localhost:8888 • IPyKernel

Como Inicializar o Jupyter

Com o ambiente ativado no terminal, execute o comando:

jupyter notebook

O comando iniciará um servidor local e abrirá automaticamente o navegador padrão exibindo o Jupyter Dashboard.

Navegação e Criação de Cadernos

  • 1. Criar novo caderno: No canto superior direito, clique em New → Python 3 (ipykernel).
  • 2. Renomear o caderno: Clique sobre o título "Untitled" no topo da página e atribua um nome ao projeto (ex.: Minha_Aula_1).
  • 3. Guardar o trabalho: Clique no ícone de disquete ou pressione o atalho Ctrl + S para gravar as alterações no arquivo .ipynb.

Tipos de Células: Código (Code) vs Documentação (Markdown)

O Jupyter Notebook permite mesclar instruções executáveis com documentação estruturada através da alternância do tipo de célula:

💻 Célula de Código (Code)

Destinada a instruções Python executáveis. Ao rodar (Shift + Enter), o interpretador processa o código e renderiza a saída computacional logo abaixo.

📝 Célula de Texto (Markdown)

Destinada a títulos (#, ##), listas (*), anotações teóricas e explicações. Ao executar, formata o texto elegante para leitura.

⚡ Principais Atalhos de Teclado (Modo de Comando - Pressione Esc antes)

Atalho Ação Executada no Caderno
M Transforma a célula atual em Markdown (Texto).
Y Transforma a célula atual em Código Python.
A Insere uma nova célula acima (Above) da atual.
B Insere uma nova célula abaixo (Below) da atual.
D + D Pressionar D duas vezes apaga a célula selecionada.
Shift + Enter Executa a célula atual e avança para a próxima célula.
Ambiente em Nuvem

3. Prática sem Instalação: Google Colab (Tablets e Navegador)

Google Research • Cloud Hosted

Para os estudantes que utilizam tablets ou computadores sem instalação local do Anaconda, o Google Colaboratory (Colab) oferece um ambiente Jupyter hospedado na nuvem, acessível diretamente pelo navegador web com a conta Google institucional.

🌐 Acesso e Criação

  1. Acesse o endereço: colab.research.google.com
  2. Inicie sessão com sua conta Google educacional.
  3. No painel inicial que se abre, clique em Novo notebook.

📱 Operação no Ecrã Tátil (Tablets)

  • Adicionar células: Toque nos botões + Código ou + Texto no topo da página.
  • Executar código: Toque no ícone circular de Play (▶️) posicionado à esquerda de cada bloco.
  • Entrada com input(): Digite o valor na caixa que surge abaixo e confirme no teclado virtual.
  • Gravação automática: Salvo direto no Google Drive na pasta Colab Notebooks.

6. Guia Rápido de Resolução de Problemas no Laboratório

⚠️ Erro "bash: anaconda3: command not found"

O ambiente do Anaconda ainda não foi carregado na sessão atual do terminal. Execute source /home/cjovem/anaconda3/bin/activate antes de chamar o comando jupyter notebook.

⚠️ Porta ocupada ou navegador não abre

Se o navegador não abrir automaticamente, observe as mensagens no terminal: copie a URL com o token gerado (começando por http://localhost:8888/?token=...) e cole na barra de endereço.

⚠️ Teclado sem resposta no Google Colab

Se os atalhos de teclado não responderem no tablet, utilize a barra de botões superior (+ Código, + Texto) e toque duas vezes na célula para forçar a abertura do teclado tátil.
