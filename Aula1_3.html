Operadores Aplicados a Strings (Texto): O que Funciona e o que NÃO Funciona?

Sobrecarga de Operadores

Em Python, operadores como + e * são polimórficos (possuem sobrecarga): o comportamento do interpretador varia automaticamente conforme o tipo de dado envolvido. Quando aplicados a strings (str), eles não realizam cálculos numéricos, mas sim operações textuais essenciais de concatenação, repetição e pertinência!

Operador Operação com Strings Exemplo em Código Resultado Obtido Regra e Comportamento
+ Concatenação (Junção) "Super" + "Lab" "SuperLab" Une duas strings sem inserir espaços automáticos. Para separar, insira o espaço explicitamente: "Olá" + " " + "Mundo".
+= Concatenação com Atribuição msg = "Ana"; msg += " Silva" "Ana Silva" Acumula novos caracteres no final de uma variável existente (equivalente a msg = msg + " Silva").
* Repetição / Replicação "=" * 10 "==========" Multiplica a string por um número inteiro $N \ge 0$. Se $N \le 0$, resulta na string vazia "" (chave liga/desliga).
*= Repetição com Atribuição traco = "-"; traco *= 5 "-----" Replica o texto da própria variável pelo fator inteiro e regrava o resultado nela mesma.
in Pertinência (Subcadeia) "py" in "python" True Verifica se uma sequência de caracteres está contida dentro do texto. Possui a forma inversa: not in.
== / != Comparação de Igualdade "Python" == "python" False Compara caractere por caractere com base na tabela Unicode (sensível a maiúsculas e minúsculas).
🚫 Atenção: O que NÃO funciona com Strings e Dispara Erro no Python (TypeError)
  • Não é permitido somar texto com número diretamente: "Nota: " + 10 dispara TypeError: can only concatenate str (not "int") to str. É mandatório converter o número antes: "Nota: " + str(10) ou usar interpolação: f"Nota: {10}".
  • Subtração não existe para strings: expressões como "Olá mundo" - "mundo" disparam erro de tipo no Python. O operador - não apaga caracteres de um texto.
  • Divisão e Exponenciação são proibidas com strings: operações como "texto" / 2, "texto" // 2 e "texto" ** 2 não são suportadas pelo interpretador.

Atribuição Composta (Abreviada)

Permite ler o valor atual de uma variável, aplicar um cálculo e regravar nela mesma de maneira concisa:

saldo += 150 # saldo = saldo + 150
saldo -= 45 # saldo = saldo - 45
pontos *= 2 # pontos = pontos * 2
valor /= 2 # valor = valor / 2
caixas //= 12 # caixas = caixas // 12
minutos %= 60 # minutos = minutos % 60
base **= 3 # base = base ** 3

Ordem Rigorosa de Precedência (PEMDAS)

Quando uma instrução tem múltiplos operadores, o CPython avalia na seguinte hierarquia:

  1. 1º Parênteses: ( ) — Forçam e alteram a prioridade de qualquer cálculo.
  2. 2º Exponenciação: ** — Avaliada da direita para a esquerda.
  3. 3º Multiplicativos: *, /, //, % — Avaliados da esquerda para a direita.
  4. 4º Aditivos: +, - — Avaliados da esquerda para a direita.
  5. 5º Relacionais: ==, !=, >, <, >=, <= — Produzem True ou False.
⚠️ Armadilha Comum: Em media = n1 + n2 / 2, a divisão de n2 / 2 ocorre primeiro! O correto é (n1 + n2) / 2.

# 3. Saída formatada

# ============================================================ # PYTHONLAB — DESAFIO MESTRE: SIMULADOR DE REFORMA E PINTURA (AULA 1.3) # Execute esta célula diretamente no Google Colab ou Jupyter Notebook # Conteúdo permitido: Variáveis, input(), float(), int(), # Operadores Aritméticos, Precedência com () e Operador Relacional <= # (Sem uso de comandos 'if' ou funções 'def') # ============================================================ # Catálogo e constantes da loja preco_lata_18L = 87 preco_lata_9L = 45 preco_lata_2L = 10 custos_fixo = 45 rendimento = 6 # 1. ENTRADA DE DADOS print("=== SIMULADOR DE REFORMA E PINTURA DO LABORATÓRIO ===") comp1 = float(input("Digite o comprimento das paredes opostas P1 em metros (ex: 8.0): ")) comp2 = float(input("Digite o comprimento das outras duas paredes em metros (ex: 8.0): ")) alt = float(input("Digite a altura da sala em metros (ex: 6.0): ")) teto_orcamento = float(input("Digite o teto de orçamento da escola em R$ (ex: 200.00): ")) # 2. CÁLCULO DA ÁREA E CONSUMO DE TINTA area_total = 2 * (comp1 * alt) + 2 * (comp2 * alt) litros = area_total / rendimento # 3. DECOMPOSIÇÃO EM LATAS GRANDES (18L E 9L) latas_18L = litros // 18 resto_18L = litros % 18 latas_9L = resto_18L // 9 resto_9L = resto_18L % 9 # 4. DECOMPOSIÇÃO E ARREDONDAMENTO DA LATA FINAL (2L) latas_2L_cheias = resto_9L // 2 resto_2L = resto_9L % 2 # FÓRMULA ARITMÉTICA DE TETO: # - Se resto_2L for 0: (0 + 2) // 3 dá 0 (nenhuma lata extra necessária) # - Se resto_2L for 1: (1 + 2) // 3 dá 1 (adiciona 1 lata para cobrir o litro final) total_latas_2L = latas_2L_cheias + (resto_2L + 2) // 3 # 5. CÁLCULO DA SOBRA REAL DE TINTA litros_comprados = (latas_18L * 18) + (latas_9L * 9) + (total_latas_2L * 2) sobra_tinta = litros_comprados - litros # 6. CUSTO TOTAL custo_total = (latas_18L * preco_lata_18L) + \ (latas_9L * preco_lata_9L) + \ (total_latas_2L * preco_lata_2L) + \ custos_fixo # ============================================================ # 7. LÓGICA DE DECISÃO SEM USAR "IF" # ============================================================ # O operador <= gera um valor booleano: True (se dentro da verba) ou False (se estourou) orcamento_ok = custo_total <= teto_orcamento # ------------------------------------------------------------ # CONCEITO 1: TRUE VALE 1 E FALSE VALE 0 # No Python, tipos lógicos têm valor numérico exato: # int(True) -> resulta em 1 # int(False) -> resulta em 0 # ------------------------------------------------------------ aprovado = int(orcamento_ok) # Vale 1 se coube no bolso, ou 0 se estourou reprovado = 1 - aprovado # Faz o inverso: vira 0 se aprovado, ou 1 se reprovado # ------------------------------------------------------------ # CONCEITO 2: MULTIPLICAÇÃO DE TEXTO POR 0 OU 1 (CHAVE LIGA/DESLIGA) # Em Python, multiplicar texto por um número repete o texto: # - "Texto" * 1 -> resulta em "Texto" (o texto é mantido) # - "Texto" * 0 -> resulta em "" (o texto se torna vazio e desaparece) # # Juntando as duas mensagens com a soma (+): # Cenário Aprovado (aprovado=1, reprovado=0): # ("Aprovada" * 1) + ("Negada" * 0) -> "Aprovada" + "" -> "Aprovada" # # Cenário Reprovado (aprovado=0, reprovado=1): # ("Aprovada" * 0) + ("Negada" * 1) -> "" + "Negada" -> "Negada" # ------------------------------------------------------------ msg_aprovado = "Orçamento suficiente: Reforma Aprovada" msg_reprovado = "Orçamento insuficiente: Reforma Negada" resultado_final = (msg_aprovado * aprovado) + (msg_reprovado * reprovado) # 8. RELATÓRIO FINAL FORMATADO print("\n--- RELATÓRIO DE CUSTOS E VIABILIDADE ---") print(f"Área total: {area_total:.1f} m²") print(f"Litros necessários: {litros:.2f} L") print(f"Latas de 18L: {latas_18L:.0f}") print(f"Latas de 9L: {latas_9L:.0f}") print(f"Latas de 2L: {total_latas_2L:.0f}") print(f"Total de tinta comprada: {litros_comprados:.2f} L") print(f"Sobra real na lata: {sobra_tinta:.2f} L") print(f"Custo total: R$ {custo_total:.2f}") print(resultado_final)
