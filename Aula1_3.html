Atribuição Composta (Abreviada)

Permite ler o valor atual de uma variável, aplicar um cálculo e regravar nela mesma de maneira concisa:

saldo += 150 # saldo = saldo + 150
saldo -= 45 # saldo = saldo - 45
pontos *= 2 # pontos = pontos * 2
valor /= 2 # valor = valor / 2
caixas //= 12 # caixas = caixas // 12
minutos %= 60 # minutos = minutos % 60
base **= 3 # base = base ** 3

Ordem Rigorosa de Precedência (PEMDAS)

Quando uma instrução tem múltiplos operadores, o CPython avalia na seguinte hierarquia:

  1. 1º Parênteses: ( ) — Forçam e alteram a prioridade de qualquer cálculo.
  2. 2º Exponenciação: ** — Avaliada da direita para a esquerda.
  3. 3º Multiplicativos: *, /, //, % — Avaliados da esquerda para a direita.
  4. 4º Aditivos: +, - — Avaliados da esquerda para a direita.
  5. 5º Relacionais: ==, !=, >, <, >=, <= — Produzem True ou False.
⚠️ Armadilha Comum: Em media = n1 + n2 / 2, a divisão de n2 / 2 ocorre primeiro! O correto é (n1 + n2) / 2.

⭐ Atividade 1 (Modelo Resolvido): Raízes Reais por Bhaskara (ax² + bx + c = 0) Resolvido

Cálculo das raízes reais decompondo em discriminante (Δ = b² - 4ac), raiz de delta (Δ**0.5) e determinação de x1 e x2.

# 1. Entrada de Dados com conversão para float
a = float(input("Digite o coeficiente a: "))
b = float(input("Digite o coeficiente b: "))
c = float(input("Digite o coeficiente c: "))

# 2. Processamento decomposto em etapas intermediárias
delta = (b ** 2) - (4 * a * c)
raiz_delta = delta ** 0.5
x1 = (-b + raiz_delta) / (2 * a)
x2 = (-b - raiz_delta) / (2 * a)

# 3. Saída formatada
print("--- Resultados ---")
print(f"Valor de Delta: {delta}")
print(f"Raiz x1: {x1}")
print(f"Raiz x2: {x2}")

Comando da Questão (Enunciado do Problema)

Script Estruturado (Sem def / Com if)

A diretoria da escola aprovou a reforma e pintura das 4 paredes do laboratório de informática (uma sala retangular composta por dois pares de paredes opostas). Sabendo que o rendimento da tinta é de 6 m² por litro e que a loja parceira comercializa tintas em três tamanhos — Lata Grande (18 Litros) por R$ 87,00 cada, Lata Média (9 Litros) por R$ 45,00 cada e Galão Pequeno (2 Litros) por R$ 10,00 cada —, você foi encarregado de construir um programa em Python para apurar os quantitativos e verificar se os custos cabem dentro do teto financeiro disponível pela instituição antes de realizar os pedidos de compra.

Para realizar esse planejamento, obtenha via teclado (utilizando input() convertido para float) o comprimento do primeiro par de paredes opostas (comp1), o comprimento do outro par de paredes opostas (comp2), a altura da sala em metros (alt) e o teto de orçamento aprovado pela escola em Reais (teto_orcamento). Em seguida, determine a área total das 4 paredes e o consumo total de tinta.

A apuração da compra deve otimizar as embalagens em cascata: calcule primeiro as latas de 18 Litros (// 18) e a sobra (% 18); sobre essa sobra, apure as latas de 9 Litros (// 9) e a nova sobra (% 9); e sobre o restante, apure os galões de 2 Litros (// 2) e a sobra final (% 2). Se ainda restar qualquer fração de tinta avulsa (litros_sobra != 0 and litros_sobra < 2), acrescente mais 1 galão de 2 Litros (latas_cheias_2L += 1) usando uma condicional if para garantir a cobertura completa.

Na etapa financeira, compute o custo total somando as latas adquiridas multiplicadas por seus valores unitários, acrescente a taxa fixa de materiais auxiliares (pincéis, rolos, lixas e fitas de proteção) de R$ 45,00 com o operador de atribuição composta +=, e valide se o custo cabe no teto orçamentário (orcamento_ok = custo_total <= teto_orcamento). Por fim, utilize uma estrutura condicional if / else para emitir a mensagem "Orçamento suficiente: Reforma Aprovada" ou "Orçamento insuficiente: Reforma Negada", exibindo o relatório consolidado no console.

Atenção às Restrições Pedagógicas: O programa deve ser implementado sem criação de funções (def), aplicando unicamente: input(), conversão float() / int(), operadores aritméticos, precedência com parênteses (), atribuição composta +=, operador relacional <= e estruturas de decisão condicional if / else.
