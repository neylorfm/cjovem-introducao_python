Fundamentos Conceituais

O Conceito de Desvio Condicional e Fluxo de Decisão

CPython Control Flow

Até este momento, os programas executavam todas as instruções de cima para baixo de maneira estritamente linear. As estruturas condicionais permitem que o programa tome decisões e escolha caminhos diferentes de execução com base em testes lógicos que resultam em verdadeiro (True) ou falso (False).

Mapeamento Lógico de Bifurcação de Execução
            ┌──────────────────┐
            │ Condição Lógica  │
            └────────┬─────────┘
                     │
         ┌───────────┴───────────┐
  [ True ]                   [ False ]
         ▼                           ▼
┌─────────────────┐         ┌─────────────────┐
│ Bloco sob o if  │         │ Bloco sob else  │
└────────┬────────┘         └────────┬────────┘
         │                           │
         └───────────┬───────────────┘
                     ▼
         ┌───────────────────────┐
         │ Continuação do Código │
         └───────────────────────┘
1️⃣ Desvio Simples (if)

Executa o bloco subordinado apenas quando o teste lógico for verdadeiro. Se for falso, o interpretador ignora as instruções recuadas e segue o fluxo adiante.

2️⃣ Desvio Composto (if-else)

Estrutura dois caminhos mutuamente exclusivos. Se verdadeiro, executa o if; se falso, executa o else. O else nunca recebe condição própria.

3️⃣ Encadeado (if-elif-else)

Avalia uma sequência de condições em fila. A palavra elif (abreviação de else if) testa uma nova condição apenas se as anteriores tiverem resultado em False.

4️⃣ Desvios Aninhados (if em if)

Inclusão de um bloco condicional inteiro dentro de outro (recuo de 8 espaços). Ideal para validações por etapas sucessivas (ex.: idade mínima primeiro, depois treinamento).

📐 Indentação e Regras de Sintaxe (PEP 8)

Diferente de linguagens que utilizam chaves {}, o Python utiliza o espaçamento no início da linha (recuo) para determinar a hierarquia do código:

  • Padrão Oficial (PEP 8): O recuo padrão deve conter rigorosamente 4 espaços em branco por cada nível de profundidade.
  • Tecla Tab: Tanto no Jupyter Notebook quanto no Google Colab, a tecla Tab já insere 4 espaços automaticamente.
  • Erro Comum (IndentationError): Misturar quantidades diferentes de espaços no mesmo bloco interrompe o interpretador imediatamente.
  • Dois-Pontos Obrigatórios (:): Toda instrução de cabeçalho condicional (if, elif, else) deve obrigatoriamente terminar com :.

CPython Internals

Memória Stack vs Heap e Avaliação de Curto-Circuito (Short-Circuit)

Short-Circuit Evaluation

No CPython, os operadores lógicos and e or operam por avaliação de curto-circuito: o Python só avalia o segundo operando se for estritamente necessário para determinar o resultado final. Se no comando if (A and B): o teste A for falso, o interpretador nem sequer executa o teste B!

# Expressão lógica avaliada na memória CPython:
media = 8.5
tem_advertencia = False
elegivel = (media >= 8.0) and (not tem_advertencia)
📚 CALL STACK (Frame Local) Ponteiros
media ➔ 0x7FC01
tem_advertencia ➔ 0x7FC02
elegivel ➔ 0x7FC03
📦 HEAP SPACE (Objetos na RAM) Alocação
[0x7FC01] tipo: float 8.5
[0x7FC02] tipo: bool False
[0x7FC03] tipo: bool True
⚠️ Ponto de Atenção Didático: No comando if (A and B):, se o teste A for avaliado como False, o interpretador nem sequer executa o teste B, pois uma conjunção lógica com a primeira parte falsa jamais poderá resultar em verdadeiro!

# Solução Oficial do Desafio Mestre: Seleção de Monitoria
def avaliar_monitoria(nome, nota_prog, media_geral, freq, susp, outra_bolsa, carga):
    tem_susp = susp.lower() == "sim"
    tem_outra = outra_bolsa.lower() == "sim"
    
    # Validação lógica única com operadores combinados
    apto = (nota_prog >= 8.5 or media_geral >= 8.0) and (freq >= 80.0) and (not tem_susp) and (not tem_outra)
    
    if apto:
        if carga == 10:
            remuneracao = 400.0
        elif carga == 20:
            remuneracao = 700.0
        else:
            print("Carga horária inválida!")
            return False
            
        bonus_aplicado = False
        if media_geral >= 9.5:
            remuneracao += 100.0
            bonus_aplicado = True
            
        print("Parecer: INSCRIÇÃO DEFERIDA")
        print(f"Bolsista: {nome}")
        print(f"Carga Horária: {carga}h")
        if bonus_aplicado:
            print("Bônus de Excelência: Aplicado (+ R$ 100.00)")
        print(f"Remuneração Final: R$ {remuneracao:.2f}")
        return True
    else:
        print("Parecer: INSCRIÇÃO INDEFERIDA")
        if tem_susp:
            print("Motivo: Candidato possui penalidade disciplinar ativa no semestre.")
        elif freq < 80.0 and (nota_prog < 8.5 and media_geral < 8.0):
            print("Motivo: Índice de frequência insuficiente e média abaixo do corte.")
        elif freq < 80.0:
            print("Motivo: Frequência abaixo do mínimo de 80%.")
        elif tem_outra:
            print("Motivo: Acúmulo de bolsa não permitido.")
        else:
            print("Motivo: Média acadêmica insuficiente para o corte.")
        return False

Ao digitar : no final de if, elif ou else e pressionar Enter, o Jupyter adiciona 4 espaços automaticamente. Se receber IndentationError, use as teclas Tab (recuar) ou Shift + Tab (desfazer recuo) para alinhar o bloco.

No Tablet / Celular (Google Colab):

Utilize a tecla virtual de seta para a direita ⇥ (Tab) da barra de ferramentas do Colab. Observe as guias verticais pontilhadas na tela: comandos na mesma guia pertencem ao mesmo nível hierárquico.
