Memória RAM, Bits e Identificadores

  • Bits e Bytes: O computador armazena instruções em sinais binários (0 e 1). 8 bits formam 1 byte.
  • Variáveis em Python: São etiquetas de texto nomeadas criadas para referenciar e recuperar dados alocados na memória física.
Regras Oficiais para Nomes de Variáveis:
  • Devem iniciar com letra (a-z, A-Z) ou sublinhado (_).
  • Não podem iniciar com números nem conter espaços ou caracteres especiais (@, -, !).
  • O Python é case-sensitive: idade, Idade e IDADE são 3 variáveis completamente distintas!

Entrada, Saída e Type Casting

  • print(...): Envia dados para o console. Permite múltiplos valores separados por vírgula.
  • type(...): Revela a classe/tipo interno do dado (ex: type(35) ➔ <class 'int'>).
  • int(input(...)): Converte explicitamente a entrada de texto para número inteiro.
  • float(input(...)): Converte texto com ponto decimal para número flutuante.
⚠️ Armadilha Didática: Concatenação Acidental

Tudo devolvido por input() é texto (str), mesmo dígitos! Se o usuário digitar 10:
• valor + 5 dispara TypeError (não soma str com int);
• valor + valor resulta no texto "1010", e não na soma 20!

Tarifa subsidiada: R$ 2,20 | Operadores de Divisão Inteira (//) e Resto (%)

🔗 Abrir Google Colab ↗

Implemente o algoritmo de recarga para o terminal de bilhetagem estudantil. O sistema deve coletar o nome do estudante (str), o cartão (str), o saldo remanescente (float) e a recarga em dinheiro (float). Calcule o novo saldo, a quantidade inteira de passagens a R$ 2,20 com // e a sobra financeira residual com %.

Saldo Total
saldo_total = saldo_anterior + recarga
Passagens Disponíveis
passagens = int(saldo_total // 2.20)
Saldo Residual
saldo_residual = saldo_total % 2.20

# Coleta com conversão explícita de tipos
nome = input("Nome do estudante: ")
cartao = input("Número do cartão: ")
saldo_anterior = float(input("Saldo remanescente: "))
recarga = float(input("Valor da recarga: "))

# Processamento aritmético
saldo_total = saldo_anterior + recarga
passagens = int(saldo_total // 2.20) # Divisão inteira
saldo_residual = saldo_total % 2.20 # Resto da divisão

# Saída formatada
print(f"Novo Saldo: R$ {saldo_total:.2f}")
print(f"Passagens disponíveis: {passagens}")
print(f"Saldo residual: R$ {saldo_residual:.2f}")
