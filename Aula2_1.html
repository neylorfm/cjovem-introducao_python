1. O Conceito de Coleção de Dados e a Estrutura de Tuplas

CPython Data Structures

Até o momento, cada variável armazenava apenas um valor primitivo isolado (como um único número inteiro, decimal ou texto). Uma coleção (ou estrutura de dados) permite agrupar múltiplos valores sob um mesmo identificador. Isso viabiliza modelar entidades reais com múltiplos atributos — como as coordenadas de um ponto geográfico, as dimensões de um objeto ou o conjunto de notas de um estudante — gerando códigos mais limpos, eficientes e legíveis.

Variáveis Isoladas (Primitivas) 
base = 5.0
altura = 7.0

Variáveis desconectadas na memória. O programador precisa rastrear cada nome individualmente.

Coleção Única (Tupla) 
retangulo = (5.0, 7.0)

Valores agrupados logicamente em um único objeto indexado e imutável.

A Estrutura de Dados Tupla (tuple)

🔢
1. Ordenação

Os elementos ocupam posições fixas e bem definidas da esquerda para a direita (índices 0, 1, 2...).

🔒
2. Imutabilidade

Uma vez alocada na memória, a tupla não permite adicionar, remover ou reatribuir elementos individuais.

🧩
3. Heterogeneidade

Pode conter elementos de tipos primitivos distintos simultaneamente (int, float, str, bool).

Formas de Declaração de Tuplas

Modalidade Sintaxe Python Tipo Inferido Regra Sintática Crucial
Tupla Vazia tupla_vazia = () tuple Coleção vazia sem elementos alocados.
Múltiplos Elementos dimensoes = (10, 20, 30) tuple Itens separados por vírgula dentro de parênteses.
Tupla Unitária (1 item) serie = ("2º Ano",) ou n = (5,) tuple Vírgula final obrigatória! Sem vírgula, (5) é interpretado como int!
Tupla sem Parênteses coordenadas = 12.5, -38.2 tuple O Python reconhece a vírgula e empacota automaticamente como tupla.
⚠️ Alerta Pedagógico da Vírgula Obrigatória:
(5) possui parênteses matemáticos de precedência ➔ Tipo: int.
(5,) possui a vírgula separadora de coleção ➔ Tipo: tuple.
Sempre que for criar uma tupla com apenas um único elemento, a vírgula final é estritamente obrigatória!

Acesso por Indexação e Desempacotamento (Unpacking)

Os elementos são acessados via colchetes tupla[indice]. O Python suporta indexação bidirecional:

Mapeamento Bidirecional de Índices em Tupla
Tupla:      notas = (  6.5,    7.8,   10.0,    9.1  )
Positivo:            [0]     [1]     [2]     [3]   (da esquerda para a direita: 0 até N-1)
Negativo:           [-4]    [-3]    [-2]    [-1]   (da direita para a esquerda: -1 é o último)
📦 Desempacotamento (Unpacking) Simultâneo

Permite extrair simultaneamente os itens da tupla para variáveis individuais sem precisar de uma linha de indexação para cada valor: 

retangulo = (5.0, 7.0)
base, altura = retangulo  # base recebe 5.0 e altura recebe 7.0
⚠️ Regra Obrigatória: A quantidade de variáveis à esquerda da igualdade deve ser exatamente igual ao número de itens na tupla (caso contrário, o Python lança ValueError).

Funções Embutidas (Built-in Functions) Essenciais para Coleções

Funções nativas da linguagem que operam diretamente sobre coleções numéricas:

Função Finalidade Exemplo de Aplicação Resultado
len(colecao) Retorna a quantidade total de itens (comprimento) len((4, 8, 15)) 3
sum(colecao) Soma todos os elementos numéricos da coleção sum((10, 20, 30)) 60
max(colecao) Identifica o maior elemento contido na tupla max((5, 12, 3)) 12
min(colecao) Identifica o menor elemento contido na tupla min((5, 12, 3)) 3
abs(numero) Devolve o valor absoluto / módulo (desconsidera sinal negativo) abs(-15.4) 15.4
