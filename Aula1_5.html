1. O Conceito de Laço de Repetição (Loop) e Controle de Fluxo

CPython Iteration Engine

Até a aula anterior, os algoritmos executavam as instruções sequencialmente ou tomavam desvios de caminho único (if-elif-else). Os laços de repetição permitem executar um mesmo conjunto de instruções várias vezes de maneira automatizada, evitando a duplicação manual de código e viabilizando o processamento de grandes volumes de dados.

Mapeamento Lógico de um Ciclo de Repetição
            ┌────────────────────────┐
            │  Bloco Anterior ao Laço │
            └───────────┬────────────┘
                        │
            ┌───────────▼────────────┐
     ┌──────>│    Condição Lógica     │
     │       └───────────┬────────────┘
     │                   │
  [ Repetir: True ]      │             [ Encerrar: False ]
     │                   ▼                      │
     │       ┌────────────────────────┐         │
     └───────┤ Bloco Interno (Iteração)│         │
             └────────────────────────┘         ▼
                                         ┌────────────────────────┐
                                         │ Bloco Posterior ao Laço │
                                         └────────────────────────┘
🔁 1. O Laço while (Enquanto-Faça)

Executa o bloco delimitado enquanto a condição lógica permanecer True. Indicado quando não sabemos previamente quantas vezes o laço irá rodar (ex.: validação contínua até o usuário digitar o valor correto).

  • Inicialização: Declaração de contadores ou sentinelas antes do laço.
  • Condição: Teste booleano avaliado antes de cada volta.
  • Atualização (Passo): Alteração obrigatória (+= ou -=) para evitar loop infinito.
🎯 2. O Laço for (Para-Cada-Em)

Em Python, o for itera diretamente sobre os elementos de uma sequência (listas, tuplas, strings) ou intervalos gerados por range(). A cada ciclo, a variável recebe automaticamente o próximo item.

  • Iteração Direta: for item in lista: percorre item a item sem precisar gerenciar índices manualmente.
  • Iteração por Índice: for i in range(len(lista)): permite acessar ou correlacionar múltiplas listas.
  • Controle de Ciclo: Encerra naturalmente ao esgotar os itens da coleção.

A Função Geradora range() sob Demanda

Gera sequências numéricas de inteiros sob demanda, consumindo espaço constante na memória RAM (lazy evaluation):

Sintaxe Início (Start) Fim (Stop - Exclusivo) Passo (Step) Sequência Produzida
range(5) 0 (padrão) 5 (para no 4) +1 (padrão) 0, 1, 2, 3, 4
range(2, 7) 2 7 (para no 6) +1 (padrão) 2, 3, 4, 5, 6
range(10, 0, -2) 10 0 (para no 2) -2 (decrescente) 10, 8, 6, 4, 2
range(10, 0, 2) 10 0 +2 (incompatível) Intervalo Vazio (0 iterações)

Modificadores de Fluxo: break, continue e Cláusula else

🛑 break

Interrompe a execução do laço imediatamente e salta para a primeira instrução após o laço. Cancela a cláusula else.

⏭️ continue

Interrompe apenas a iteração atual e avança diretamente para a próxima repetição do laço.

✅ Cláusula else no Laço

Bloco executado exclusivamente quando o laço percorre todas as voltas sem ser interrompido por um break.

2. Diagrama de Memória CPython (Stack vs Heap no Loop)

Imutabilidade de Inteiros

Em Python, inteiros são objetos imutáveis. Acompanhe o que acontece na memória quando uma variável contadora sofre incrementos numéricos sucessivos (contador += 1):

# Código em Execução
contador = 0
while contador < 3:
    contador += 1
PASSO 0 (Inicialização: contador = 0)
Call Stack: contador ➔ ponteiro 0x7FA00
Heap: [0x7FA00] int = 0
PASSO 1 (Após a volta 1: contador += 1)
Call Stack: contador ➔ novo ponteiro 0x7FA01
Heap: [0x7FA01] int = 1 (o objeto 0 foi descartado)
⚠️ Alerta Pedagógico: Como números inteiros em Python são objetos imutáveis, a cada incremento a variável aponta para um novo endereço de memória na Heap. Se a instrução de incremento for omitida, a condição permanecerá verdadeira infinitamente, travando o programa e sobrecarregando a CPU!

Atividade 2.0 (Resolvida) — Análise de Temperaturas do Laboratório Gabarito Modelo

Dada uma lista de temperaturas diárias registradas no laboratório, percorra a lista diretamente para exibir os valores, acesse os dados por índice numérico para identificar o dia da semana correspondente e acumule a soma de todas as medições para calcular a média semanal consolidada.

# Resolução Modelo
temperaturas = [24.5, 26.0, 23.5, 28.0, 25.0]

print("--- 1. Iteração Direta ---")
for temp in temperaturas:
    print(f"Temperatura aferida: {temp}°C")

print("\n--- 2. Acesso por Índice ---")
for i in range(0, len(temperaturas), 1):
    print(f"Dia {i + 1} -> Leitura: {temperaturas[i]}°C")

print("\n--- 3. Acumulador de Média ---")
soma_total = 0.0
for temp in temperaturas:
    soma_total += temp

media = soma_total / len(temperaturas)
print(f"Média semanal consolidada: {media:.2f}°C")

Desafio Prático 2: Análise de Rendimento do Atleta +50 XP • for & range(len)

Dada a lista tempos = [12.4, 11.8, 13.1, 11.5, 12.0] com as voltas de um atleta em segundos, use for por índice para exibir cada volta, determine a volta mais rápida (menor tempo) e a mais lenta (maior tempo) sem usar bibliotecas externas (apenas comparando valores com if), e calcule a média final. 

tempos = [12.4, 11.8, 13.1, 11.5, 12.0]

soma = 0.0
mais_rapido = tempos[0]
mais_lento = tempos[0]

for i in range(len(tempos)):
    atual = tempos[i]
    print(f"Volta {i + 1}: {atual}s")
    soma += atual
    
    if atual < mais_rapido:
        mais_rapido = atual
    if atual > mais_lento:
        mais_lento = atual

media = soma / len(tempos)

sensores = [100, 95, 0, 88, -99, 92]

    if lote == 0:
        print("Sensor nulo ignorado pelo filtro.")
        continue

        print(f"PERIGO: Curto-circuito detectado ({lote})! Linha paralisada.")
        break
    print(f"Sensor em operação: {lote}% de integridade.")

Desafio Prático 5: Verificador de Números Primos +50 XP • Flag Booleana & break

Solicite ao usuário um número inteiro N maior que 1. Utilizando uma variável de controle booleana e_primo = True e um laço for divisor in range(2, N):, teste se o número possui algum divisor exato (N % divisor == 0). Se possuir, defina e_primo = False e encerre com break. Ao final, exiba se o número digitado é ou não primo. 

n = int(input("Digite um número inteiro maior que 1: "))
e_primo = True

for divisor in range(2, n):
    if n % divisor == 0:
        e_primo = False
        break

if e_primo and n > 1:
    print(f"O número {n} é PRIMO!")
else:
    print(f"O número {n} NÃO é primo.")
